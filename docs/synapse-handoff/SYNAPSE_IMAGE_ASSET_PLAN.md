# SYNAPSE — IMAGE SOURCING AND ASSET HANDOFF

Use the image plan in Section 12 of `SYNAPSE_ANTIGRAVITY_BUILD_BRIEF.md` as the full image specification.

## Principles
- Use restrained, documentary-style stock photography for generic learning contexts.
- Use authentic Synapse/Chamba photographs for the local venture cards wherever possible.
- Never caption a generic stock photo as a real artisan, Chamba property, Synapse class or local farm.
- Download chosen stock photos into the project. Do not embed Unsplash search pages, use hotlinked search thumbnails, or use paid Getty/iStock assets without a licence.
- Keep photographer/source details in `public/images/image-credits.md`.
- Obtain appropriate permission for identifiable people, especially minors and local artisans/hosts.
